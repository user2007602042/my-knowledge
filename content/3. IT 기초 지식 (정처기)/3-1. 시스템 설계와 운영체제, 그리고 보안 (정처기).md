#개발기초 

소프트웨어라는 건물을 짓고 안전하게 운영하기 위해 반드시 알아야 할 3가지 핵심 원리를 정리한다.

## 1. MVC 패턴 (Model-View-Controller) : 식당의 완벽한 분업 시스템
어떤 웹사이트나 프로그램을 만들 때, 코드를 뒤죽박죽 섞어 짜지 않고 **역할별로 3가지 구역으로 철저하게 나누어 개발하는 가장 유명한 설계 방식**이다.

[Image of MVC Model View Controller architecture diagram]

* **Model (모델 / 주방장과 식재료 창고):**
    * **역할:** 데이터와 비즈니스 로직을 담당한다. 데이터베이스에서 정보를 빼오고, 계산하고, 저장하는 '머리' 역할이다.
    * **특징:** 화면(View)이 어떻게 생겼는지 전혀 모른다. 오직 데이터 가공에만 집중한다.
* **View (뷰 / 플레이팅과 손님 테이블):**
    * **역할:** 사용자의 눈에 보이는 화면(UI)을 담당한다. (HTML, CSS 등)
    * **특징:** 주방(Model)에서 무슨 일이 일어나는지 모른다. 그저 받은 음식을 예쁘게 그릇에 담아 보여주기만 한다.
* **Controller (컨트롤러 / 홀 매니저):**
    * **역할:** 손님(사용자)의 주문을 받아서 주방(Model)에 지시하고, 완성된 요리를 테이블(View)로 가져다주는 '중간 다리' 역할이다.

> **💡 왜 이 패턴을 쓸까? (유지보수의 마법)**
> 식당 테이블(View)의 색깔을 바꾼다고 해서 주방장(Model)이 요리법을 바꿀 필요가 없다. 즉, **디자인을 수정할 때 내부 데이터 로직을 건드리지 않아도 되기 때문에** 유지보수가 엄청나게 편해진다.

## 2. 프로세스와 스레드 (Process & Thread) : 운영체제의 작업 반장들
컴퓨터(운영체제)가 여러 가지 프로그램을 동시에 실행할 때 자원을 나누어주는 방식이다.

* **프로세스 (Process) : '독립된 건설 현장'**
    * 실행 중인 하나의 프로그램(예: 엑셀 1개, 크롬 1개).
    * 각 프로세스는 운영체제로부터 **자신만의 독립된 땅(메모리)과 자원**을 할당받는다.
    * 현장(프로세스)끼리는 높은 울타리가 쳐져 있어서, A 현장에 불이 나도(크래시) B 현장에는 피해가 가지 않는다.
* **스레드 (Thread) : '현장 안에서 일하는 인부들'**
    * 하나의 프로세스 안에서 실제로 작업을 수행하는 단위.
    * 하나의 건설 현장(프로세스) 안에 여러 명의 인부(스레드)가 투입되어 동시에 작업을 진행한다.
    * 인부들은 같은 현장의 시멘트와 공구(메모리)를 **공유**하기 때문에 일 처리가 매우 빠르고 효율적이다. 하지만 한 인부가 실수로 기둥을 무너뜨리면 그 현장(프로세스) 전체가 멈춰버리는 위험도 있다.

## 3. 대칭키 vs 비대칭키(공개키) 암호화 : 현장의 보안 자물쇠
인터넷으로 중요한 설계 도면이나 비밀번호를 주고받을 때, 중간에 해커가 가로채도 볼 수 없게 만드는 암호화 기술이다.

* **대칭키 암호화 (Symmetric Key) : '공용 마스터키'**
    * **방식:** 문서를 잠글 때(암호화) 쓰는 열쇠와, 열 때(복호화) 쓰는 열쇠가 **똑같다.**
    * **장점:** 잠그고 푸는 속도가 엄청나게 빠르다.
    * **치명적 단점:** 자물쇠를 보낼 때 열쇠도 같이 보내야 하는데, 이 배송 과정에서 열쇠를 도둑맞으면 끝장이다.
* **비대칭키/공개키 암호화 (Asymmetric / Public Key) : '자물쇠와 개인 열쇠 분리'**
    * **방식:** 모두에게 공개하는 **'공개키(잠그는 용도)'**와, 나만 몰래 가지는 **'개인키(푸는 용도)'** 2개를 한 세트로 만든다.
    * **활용:** 협력업체에게 내 '공개키(열려있는 자물쇠)'를 마구 뿌린다. 협력업체는 도면을 그 자물쇠로 찰칵 잠가서(암호화) 나에게 보낸다. 이 자물쇠는 오직 내가 가진 '개인키'로만 열 수 있다! 중간에 해커가 가로채도 열쇠가 없으니 절대 열지 못한다.
    * 현대 인터넷의 안전한 연결(`https://`)을 보장하는 가장 위대한 발명 중 하나다.
