#개발기초 

바이브코딩(AI 코딩)을 하다 보면 까만 터미널 창에서 명령어를 입력해야 하는 순간이 반드시 온다. 마우스(GUI)에 익숙한 비개발자에게는 낯설지만, 컴퓨터에게 가장 빠르고 정확하게 일을 시킬 수 있는 방법이다.

## 1. GUI vs CLI: 왜 까만 창을 쓸까?


* **GUI (Graphical User Interface) = 키오스크 주문:** 바탕화면, 폴더 아이콘, 창, 마우스 클릭 등 눈에 보이는 '그래픽'을 조작하는 방식. 직관적이고 배우기 쉽지만 반복 작업에 불리하다.
* **CLI (Command Line Interface) = 텍스트 주문:** 텍스트(문자)만 쳐서 컴퓨터와 소통하는 방식. (명령 프롬프트, 터미널, 파워셸 등) 문법을 외워야 하지만 익숙해지면 마우스보다 훨씬 빠르다.

**💡 개발자들이 CLI를 고집하는 이유**
1. **압도적인 속도와 자동화:** 마우스로 폴더 100개를 만들려면 수백 번 클릭해야 하지만, 명령어 한 줄이면 0.1초 만에 끝난다.
2. **가벼움과 안정성:** 화려한 그래픽을 띄울 필요가 없어 컴퓨터 자원(CPU, 메모리)을 낭비하지 않는다.
3. **정확한 기록 (명확성):** 텍스트로 입력한 명령어가 그대로 기록에 남기 때문에, 작업 이력을 추적하거나 다른 사람에게 "이거 복사해서 쳐!"라고 전달하기 매우 쉽다.

## 2. 실전 생존 명령어 베스트 10 (Windows 기준)
터미널 창을 열고 아래 명령어들을 직접 타이핑하며 감을 익혀보자. 

### 📂 ① 폴더 탐색 및 이동 (마우스 더블클릭/뒤로가기 대체)
* `dir` : 현재 내가 있는 폴더 안에 어떤 파일과 폴더들이 있는지 목록을 쫙 보여준다. (Directory)
* `cd 폴더이름` : 지정한 폴더 안으로 들어간다. (Change Directory)
  * *예시: `cd Desktop` (바탕화면으로 이동)*
* `cd ..` : 현재 폴더에서 빠져나와 상위(바깥) 폴더로 한 칸 되돌아간다. 

### 📝 ② 파일과 폴더 관리 (마우스 우클릭 대체)
* `mkdir 폴더이름` : 현재 위치에 새로운 텅 빈 폴더를 만든다. (Make Directory)
  * *예시: `mkdir quartz_test`*
* `rmdir 폴더이름` : 비어있는 폴더를 삭제한다. (Remove Directory)
* `del 파일이름` : 특정 파일을 휴지통을 거치지 않고 영구 삭제한다. (주의해서 사용!)
  * *예시: `del index.txt`*

### 💻 ③ 시스템 & 네트워크 (해커 느낌 내기 😎)
* `cls` : 이것저것 치느라 까만 화면이 지저분해졌을 때, 화면을 새것처럼 싹 지워준다. (Clear Screen, **초보자에게 가장 유용함!**)
* `ipconfig` : 내 컴퓨터의 현재 인터넷 IP 주소와 네트워크 연결 상태를 보여준다.
* `ping 웹사이트주소` : 해당 사이트로 핑(Ping) 신호를 4번 쏴서 인터넷 응답 속도와 연결 상태를 확인한다.
  * *예시: `ping google.com`*
* `systeminfo` : 내 컴퓨터의 운영체제 버전, 설치된 날짜, RAM 용량 등 시스템 전체 스펙을 길게 뽑아준다.

### 🚪 ④ 종료하기
* `exit` : 마우스로 'X' 버튼을 누르지 않고 터미널 창을 쿨하게 닫고 나간다.
