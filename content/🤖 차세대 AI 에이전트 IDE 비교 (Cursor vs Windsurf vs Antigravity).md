#AI #개발기초 

기획안을 실제 동작하는 S/W 프로토타입으로 빠르게 구현하는 '바이브코딩'의 효율을 극대화하려면, 단순한 챗봇을 넘어선 **'자율형 AI 에이전트'**가 탑재된 IDE(통합 개발 환경)가 필수적이다.

## 1. 단순 챗봇 vs 에이전트 내장형 IDE
기존 VS Code에 확장 프로그램을 붙여 쓰는 것과, 처음부터 에이전트 전용으로 설계된 IDE의 결정적인 차이는 '자율성'에 있다.

* **VS Code + 챗봇 (내비게이션):** 코드 조각을 짜주긴 하지만, 파일을 생성하고 저장한 뒤 터미널에서 실행하는 것은 결국 '사람'이 일일이 수동으로 해야 한다.
* **에이전트 IDE (자율주행차):** 코드를 짜는 것을 넘어 **새 파일로 직접 저장하고, 터미널을 열어 서버를 실행하며, 에러가 나면 스스로 에러 로그를 읽고 수정**까지 진행한다.

## 2. 대표적인 AI 에이전트 IDE 3대장

### ① Cursor (커서) : 현재 시장의 절대 강자이자 표준
* **핵심 기능:** `Composer (컴포저)`
* **특징:** 프로젝트 전체를 조망하며, 여러 개의 파일(HTML, CSS, Python 등)을 동시에 생성하고 수정하여 하나의 완성된 결과물을 조립해 낸다.

* **장점:** 바이브코딩에 가장 최적화되어 있으며, 원하는 부분만 드래그해 수정하는 능력이 탁월하다. 전 세계적으로 참고할 튜토리얼이 가장 많다.

### ② Google Antigravity (안티그래비티) : 시각적 피드백의 끝판왕
* **핵심 기능:** `Agent Manager (다중 작업 지휘)` 및 `브라우저 자동 테스트`
* **특징:** 여러 에이전트에게 비동기적으로 지시를 내릴 수 있다. 가장 큰 특징은 AI가 스스로 크롬 브라우저를 열어 작동 화면을 캡처하고, 에러 없이 버튼이 눌리는지 보고서 형태로 보여준다.
* **장점:** 복잡한 터미널 에러 창을 보지 않고, 결과물 화면 위주로 소통할 수 있어 매우 직관적이다.

### ③ Windsurf (윈드서프) : 무서운 속도로 떠오르는 신흥 강자
* **핵심 기능:** `Cascade (캐스케이드)`
* **특징:** 작업자의 코드 입력 흐름을 실시간으로 읽고 다음 단계를 먼저 제안한다. 터미널 명령어 실행부터 라이브러리 설치까지 AI와 완전히 한 몸이 된 것처럼 물 흐르듯 진행된다.
* **장점:** 백엔드 로직 디버깅이나 터미널 환경 설정 등, 에러 로그를 끈질기게 분석하는 개발자 친화적인 작업에 강력하다.
